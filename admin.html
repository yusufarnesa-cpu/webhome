🧠 Kelola CBT

Buat CBT dengan memasukkan soal dari AI dalam format JSON. Untuk CBT besar, gunakan sistem 4 batch agar tidak terbentur batas panjang output AI.

🚀 Sistem CBT 4 Batch

Buat soal menggunakan AI dengan pembagian:
• Batch 1 → Soal 1–25
• Batch 2 → Soal 26–50
• Batch 3 → Soal 51–75
• Batch 4 → Soal 76–100

Setelah keempat JSON ditempel, sistem akan otomatis menggabungkannya menjadi 1 CBT dengan 100 soal.

Informasi CBT

Paste JSON Batch

Format setiap batch harus seperti ini:
{ "batch": 1, "start_question": 1, "end_question": 25, "questions": [ { "question": "Pertanyaan...", "options": [ "Pilihan A", "Pilihan B", "Pilihan C", "Pilihan D", "Pilihan E" ], "answer": 2, "explanation": "Penjelasan..." } ] }

Duplikasi

Import CBT Tunggal

Fitur ini tetap dipertahankan untuk CBT yang dibuat dalam satu JSON.

⚠️ Penting:
Nomor answer menggunakan sistem 1-based. Artinya 1 = pilihan pertama, 2 = pilihan kedua, dan seterusnya.

Format JSON CBT Tunggal

{ "title": "Ujian Anatomi THT", "description": "Ujian CBT Anatomi THT", "category": "THT", "duration_minutes": 60, "questions": [ { "question": "Apa fungsi utama tuba Eustachius?", "options": [ "Mengatur tekanan telinga tengah", "Menghasilkan serumen", "Mengatur keseimbangan tubuh", "Menghasilkan endolimfa" ], "answer": 1, "explanation": "Tuba Eustachius membantu menyamakan tekanan telinga tengah dengan nasofaring." } ] }
