🧠 Kelola CBT

Buat CBT dengan memasukkan soal dari AI dalam format JSON. Untuk CBT besar, gunakan sistem 4 batch.

🚀 Sistem CBT 4 Batch

Buat soal menggunakan AI dengan pembagian:
• Batch 1 → Soal 1–25
• Batch 2 → Soal 26–50
• Batch 3 → Soal 51–75
• Batch 4 → Soal 76–100

Setelah keempat JSON ditempel, sistem akan otomatis menggabungkannya menjadi 1 CBT dengan 100 soal.

Informasi CBT

Paste JSON Batch

Format setiap batch (dengan pembahasan per-pilihan):
{ "batch": 1, "start_question": 1, "end_question": 25, "questions": [ { "question": "Pertanyaan...", "options": [ { "text": "Pilihan A", "explanation": "Mengapa A benar / salah..." }, { "text": "Pilihan B", "explanation": "Mengapa B benar / salah..." }, { "text": "Pilihan C", "explanation": "Mengapa C benar / salah..." }, { "text": "Pilihan D", "explanation": "Mengapa D benar / salah..." }, { "text": "Pilihan E", "explanation": "Mengapa E benar / salah..." } ], "answer": 2, "explanation": "Ringkasan pembahasan soal (opsional)." } ] }

Catatan: Format lama (options berupa string) tetap didukung.

🎯 Kelola OSCE

Buat dan kelola station OSCE beserta checklist penilaiannya.

Checklist Penilaian

Tambahkan langkah pemeriksaan. Setiap langkah dapat diberikan poin 0–3.

0 = Tidak dilakukan/salah
1 = Banyak kekurangan
2 = Cukup benar, masih ada kekurangan
3 = Benar dan lengkap
