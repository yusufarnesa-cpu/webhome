🧠 Kelola CBT

Import ujian CBT beserta seluruh soal dan pilihan jawaban menggunakan JSON yang dibuat oleh AI.

Alur penggunaan:
1. Generate soal menggunakan AI.
2. Minta AI menghasilkan format JSON sesuai template di bawah.
3. Copy seluruh JSON.
4. Paste ke kotak JSON di bawah.
5. Klik Import CBT.
6. Sistem akan menyimpan ujian, soal, pilihan, dan kunci jawaban ke Supabase.
⚠️ Penting:
Nomor answer menggunakan sistem 1-based. Artinya 1 = pilihan pertama, 2 = pilihan kedua, dan seterusnya.

Format JSON

{ "title": "Ujian Anatomi THT", "description": "Ujian CBT Anatomi THT", "category": "THT", "duration_minutes": 60, "questions": [ { "question": "Apa fungsi utama tuba Eustachius?", "options": [ "Mengatur tekanan telinga tengah", "Menghasilkan serumen", "Mengatur keseimbangan tubuh", "Menghasilkan endolimfa" ], "answer": 1, "explanation": "Tuba Eustachius membantu menyamakan tekanan telinga tengah dengan nasofaring." } ] }
